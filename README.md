# Playwright Test Framework (JS & TS)

Scaffolded Playwright test framework for JavaScript and TypeScript.

Quick start

1. Install dependencies:

```bash
npm install
```

2. Install Playwright browsers (one-time):

```bash
npx playwright install
# or for CI-friendly full deps
npx playwright install --with-deps
```

3. Run tests:

```bash
npm test
```
